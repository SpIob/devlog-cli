# devlog-cli — Hermes Project Rules

## Multi-Session Workflow

### Worktrees
- Main: `/Users/spiob/Coding Projects/devlog-cli/devlog-cli` (main branch)
- Feature worktrees: `../devlog-cli-<branch-slug>`

Run `devlog-cli` (or `hermes --profile devlog-cli`) from the respective worktree root.

### Agent Locks
Before editing high-conflict files, claim a lock:

```bash
./scripts/agent-lock.sh claim <file> "<description>"
./scripts/agent-lock.sh release <file>
./scripts/agent-lock.sh check
```

### High-Conflict Files (claim before editing)
- `devlog/storage.py` / `devlog/storage/` — storage layer refactor
- `pyproject.toml` — dependencies, versions, tool config
- `devlog/cli/*.py` — command registry changes
- `devlog/__init__.py` — version bumps
- `CHANGELOG.md` — release notes
- `devlog/sqlite_storage.py` — SQLite backend
- `devlog/_dates.py`, `devlog/_tagops.py`, `devlog/_time.py` — shared internals

### Creating Worktrees
```bash
./scripts/new-worktree.sh <branch-slug> <base-branch>
# Example: ./scripts/new-worktree.sh storage-refactor main
# Creates ../devlog-cli-storage-refactor with branch 'storage-refactor'
```

## Build & Test
- Test: `.venv/bin/python -m pytest tests/ -x -q`
- Lint: `.venv/bin/ruff check devlog/ tests/`
- Format: `.venv/bin/ruff format devlog/ tests/`
- Type-check (if added): N/A

## Parallel Session Protocol
1. Claim lock for any file in "High-Conflict Files"
2. Work in a git worktree (not main repo directly) for sustained feature work
3. Run tests before committing
4. Release lock when done

## Kanban (profile-scoped)
```bash
devlog-cli kanban list --tenant devlog-cli-main
devlog-cli kanban create "Task" --tenant devlog-cli-main --assignee devlog-cli
```

## Cron (profile-scoped)
```bash
devlog-cli cron list
# Scripts go in ~/.hermes/profiles/devlog-cli/scripts/
```

## Storage Backends
- JSON (default): `DEVLOG_BACKEND=json`
- SQLite: `DEVLOG_BACKEND=sqlite`

Both use `DEVLOG_DATA_DIR` env var for custom data directory.

## Entry Format
- IDs: UUID4 (lowercase), short-prefix lookup supported
- Timestamps: UTC ISO 8601 `YYYY-MM-DDTHH:MM:SSZ`
- Tags: lowercase alphanumeric + hyphen, max 32 chars

## Notable Commands
| Command | Purpose |
|---|---|
| `devlog add "msg" -t tag1,tag2` | Add entry |
| `devlog list` / `devlog show <id>` | View entries |
| `devlog search <query>` | Full-text search |
| `devlog stats` | Stats v2 (streaks, tag co-occurrence) |
| `devlog calendar` | Calendar heatmap |
| `devlog theme` | Theme management |
| `devlog backup` / `devlog restore` | Backup & restore |
| `devlog undo` | Single-step undo |
| `devlog repair` / `devlog doctor` | Validate & repair storage |
| `devlog mcp serve` | MCP server mode |
